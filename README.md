# ST 558 Project 2 - Melbourne Housing Explorer

This repository contains my Project 2 Shiny application for ST 558.

The Melbourne Housing Explorer allows users to interactively filter and explore residential property data from Melbourne, Australia.

Users can:

- Filter properties by property type and region
- Filter using two selected numeric variables
- View one-way and two-way contingency tables
- Create grouped numerical summaries
- Generate multiple types of visualizations
- View and download the filtered dataset

The repository also contains `exploration.qmd`, which includes the static exploratory analysis used to plan the Shiny application.

## Data

The project uses the Melbourne Housing Market dataset.
